# Datos originales

`weatherAUS.csv` se conserva tal como fue descargado y no se modifica en ningun paso del pipeline.

- Origen: Oficina de Meteorologia de Australia (Bureau of Meteorology), version "Rain in Australia" de Kaggle
  (https://www.kaggle.com/datasets/jsphyg/weather-dataset-rattle-package), copia en https://github.com/acakin/weatherAUS.
- Contenido: 145.460 observaciones diarias, 49 estaciones, 2007-11-01 a 2017-06-25.
- Si falta el archivo, descargarlo desde esos enlaces y guardarlo aqui con el nombre `weatherAUS.csv`.

El resultado del pipeline se guarda en `datos/procesados/dataset_limpio.csv`.
