# Datos

Archivo: `datos/weatherAUS.csv` (14 MB, 145.460 registros y 23 variables).

- Contenido: observaciones meteorologicas diarias de 49 estaciones de Australia, 2007-11-01 a 2017-06-25.
- Origen: Oficina de Meteorologia de Australia (Bureau of Meteorology). Version difundida como "Rain in Australia" en Kaggle
  (https://www.kaggle.com/datasets/jsphyg/weather-dataset-rattle-package) y copiada en https://github.com/acakin/weatherAUS.
- Uso: academico, citando la fuente. Los valores faltantes vienen como `NA`.
- Fecha de consulta: 2 de noviembre de 2026.

Si el archivo no esta, descargarlo desde cualquiera de los enlaces anteriores y guardarlo en esta carpeta con el nombre `weatherAUS.csv`.
