# Comportamiento climatico integrado - Avance 1

Proyecto 4 de Programacion Avanzada. Estudia temperatura, humedad, presion atmosferica y velocidad del viento
usando observaciones diarias de estaciones meteorologicas de Australia.
Este avance cubre la definicion del problema, la fuente de datos, el diccionario, el diseno del pipeline y la carga inicial con Pandas.

Integrantes: Patricio Parra, Benjamin Carrillo, Simon Leiva. Secciones 1 y 2, profesor Alex.

## Estructura

    datos/weatherAUS.csv   dataset original
    datos/README.md        procedencia del dataset
    reportes/avance_1.pdf  informe del avance
    src/carga.py           carga e inspeccion con Pandas
    main.py                punto de entrada

## Ejecucion

Desde la raiz del proyecto:

    pip install -r requirements.txt
    python main.py
